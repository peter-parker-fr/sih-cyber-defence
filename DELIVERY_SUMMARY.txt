## 🧠 ML Model Details

### LSTM World Model
- **Input:** 16 engineered network flow features
- **Architecture:** 2-layer LSTM, 64 hidden units
- **Attention:** Feature importance mechanism
- **Output:** Infiltration probability (0-1)
- **Training:** 500 synthetic flows
- **Inference:** <250ms per prediction

### Threat Classification
- **Reconnaissance:** Initial probing behavior
- **Initial Access:** Exploitation attempts
- **Lateral Movement:** Horizontal traversal
- **Command & Control:** Beaconing patterns
- **Exfiltration:** Data theft activity

### Feature Engineering
- TCP flags analysis (SYN, ACK, FIN, RST)
- Flow statistics (bytes/packet, rate)
- Inter-arrival time metrics
- Port-based anomalies
- Bidirectional ratios
